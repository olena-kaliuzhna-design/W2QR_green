W2QR Encryption

Unbreakable by Design

Any password produces a valid wallet. There is no way to know which result is the real one. An attacker who tries every possible password gets millions of valid-looking wallets — but has no way to tell which one holds real funds.

Why most encryption fails against brute force

Most encryption produces random garbage when you enter the wrong password. An attacker trying passwords can instantly tell when they guess correctly — the output suddenly turns into readable data.

Wrong password→d7 3f a1 02 b8 … (garbage)
Correct password→abandon ability … (valid words!)

The attacker knows the moment they succeed — the output changes from random bytes to real words.

W2QR: every password creates a real wallet

W2QR uses a fundamentally different approach. Every password produces a valid wallet with real words. The attacker has no signal — every attempt looks correct. There is no way to reject a wrong guess.

Password: "cat123"→abandon ability cable …
Password: "MyDog!"→fossil grape hello …
Password: "S3cur3!!"→ocean pepper quiz …
Password: "tryMe99"→valley winter zone …

Every result is a real seed phrase controlling a real wallet. Only the correct password (highlighted) produces your wallet — but there is no way to tell which one it is without checking the blockchain.

How it works

Creating your backup

Your seed phrase+Your password=Encrypted QR

Unlocking with any password

Encrypted QR+Any password=A valid wallet

The math behind the encryption guarantees that every password — right or wrong — produces a valid set of wallet words. Each attempt takes about half a second due to the memory-intensive key derivation, making mass guessing slow and expensive.

What an attacker faces

  1. They obtain your QR code — they have the encrypted data.

  2. They try a million passwords — each one takes ~0.5 seconds. That alone takes about 6 days.

  3. They get a million valid wallets — every single one looks real. No errors, no failures. Just a million wallets.

  4. They must check each one on the blockchain — look up balances for every wallet on every network. Expensive and slow.

  5. Result: not worth trying — the combination of slow password processing and mandatory blockchain checking makes brute force economically pointless.

Additional layers make it even harder

Even without any extras, the encryption is already impractical to crack. But W2QR offers additional security layers that make brute force completely impossible — even for an attacker who has your QR and knows your password.

  • Strong Password Generator — derive a quantum-resistant password from a memorable phrase. Over 150 bits of entropy makes exhaustive search infeasible by any known technology.
  • Plastic Cards — print your wallet QR and password QR on separate credit-card-sized cards. Keep them in different locations for physical two-factor access.

Each layer multiplies the difficulty. With even one additional factor, brute force goes from “economically pointless” to “mathematically impossible.”

Honey Encryption in W2QR Cards

A W2QR Card contains random bytes that are already valid honey-encrypted data. When you activate the card with a password, honey decryption produces a valid BIP-39 mnemonic. Every password produces a different, valid seed phrase — the password you choose during activation determines which wallet is yours.

Card QR + password A→abandon ability cable ...
Card QR + password B→fossil grape hello ...
Card QR + password C→ocean pepper quiz ...

An attacker who obtains the card cannot determine which password was used to activate it. The QR data looks random, every password produces a valid wallet, and there is no password oracle or verifier. Only the user who chose the password knows which wallet is theirs.

Plastic cards preserve honey encryption

A pre-printed W2QR plastic card uses the same honey encryption as any W2QR wallet. The printed QR code does not change after activation. The honey encryption guarantee remains intact: any password still produces a valid wallet from the printed QR. You can optionally back up to Google Drive after activation.
